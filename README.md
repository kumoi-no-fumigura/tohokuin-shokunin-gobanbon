## 作品について

建保二年（1214）秋、東北院の念仏に集まった職人たちが、月と恋を題に歌を合わせたという設定の職人歌合。医師と陰陽師など十人の職人を五番に組み、経師が判者を務める。十二番本より古い形とされる五番本で、東京国立博物館所蔵の絵巻（重要文化財）を底本とする。

## 本文の作り方

東京国立博物館の公開画像を、国立国会図書館の NDL古典籍OCR-Lite でテキスト化し、プログラムで歌ごと（詞書・作者・左注を分けて）に段落に分けました。写本の崩し字の OCR なので、誤りが多く残っています。

## ファイル

| パス | 中身 |
|---|---|
| `honbun/` | 本文。1 行が 1 首で、`段落ID<TAB>番号<TAB>詞書<TAB>作者<TAB>歌<TAB>左注` の形です。番号は、この作品の中での歌の通し番号（1 から。序などの歌でない段落は空）です。50段落ごとにファイルを分けています（1ファイル）。 |
| `uta.tsv` | 作中歌の一覧（番号・段落ID・本文・読み・詠み手・種別・原本のコマ）。 |
| `tnm-tohokuin-shokunin.json` | 本文・底本・作品の説明・作中歌のデータをまとめた JSON（訳は入れず、`yaku/` だけに置いています）。 |

段落ID（例: `tnm-tohokuin-shokunin-000001`）は、本文を直しても変わりません。
